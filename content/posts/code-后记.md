这个栏目讲的是十四种语言和一个平台的故事。从 Fortran 到 GitHub，从 1957 年到 2026 年。

但还有更多值得讲的故事没有讲进来。COBOL——今天全世界的银行还在跑着几十亿行它写的代码。Smalltalk——图形界面、鼠标、窗口，1972 年在实验室里就全部做出来了。Perl——文本处理的王者，正则表达式至今无人超越，却败在了可读性上。还有 Ada、Pascal、Erlang、Lua、Dart、Kotlin、TypeScript——每一门语言都承载了一群人的世界观和工程智慧，每一门都值得一篇独立的文章。一个专栏的篇幅装不下全部。

但选进来的这些，也有一个共同点。

John Backus 发明了编译器。John McCarthy 发明了递归和垃圾回收。Ken Thompson 和 Dennis Ritchie 两个人写出了 Unix 和 C。Edgar Codd 用一篇论文定义了关系数据库。Brendan Eich 用十天做出了统治互联网的语言。Guido van Rossum 圣诞节的无聊产物成了 AI 时代的普通话。Linus Torvalds 因为生气两周内写出的工具，二十一年后全世界还在用。

这些名字放在一起，是一份改变世界的名单。今天每一行代码、每一个网页、每一个 App，都在依赖他们七十年间设计出来的工具。操作系统是 C 写的，浏览器里跑的是 JavaScript，后端挤着 Python、Java、Go，数据库等着 SQL 的查询，代码托管在 GitHub 上。

但这些人中有几个是家喻户晓的名字？

科技行业的聚光灯永远打着那几个商业巨人——Jobs、Gates、Zuckerberg、Musk——他们在发布会的大屏幕上，在媒体的头条里。而系统底层工具的设计者们——让操作系统能跑、让数据库能查、让浏览器能渲染、让网页能动态生成的人——他们在媒体的视野之外，在维基百科的词条里，在一些被遗忘的技术会议记录里。Backus 的名字在街上被认出的概率和一张陌生面孔差不多。Stroustrup 的知名度比不上任何一个二线 YouTuber。Rasmus Lerdorf 让每个人都能搭一个动态网站，但他的名字在任何公开场合都几乎不会被提起——不是他的问题，是这个行业有一种奇怪的惯性：聚光灯不打在基础设施上。

更准确地说，这些人大多数就是程序员。不是"技术出身的企业家"，是程序员——改 bug、看文档、写注释、和同事争吵接口设计、在深夜盯着屏幕怀疑人生。Linus 写出 Git 之前也摔过键盘，Stroustrup 在 C++ 兼容 C 的问题上纠结了好几年，Guido van Rossum 在 Python 2 到 3 的迁移上栽了一个大跟头。

他们是天才，但他们也是打工人。

这或许就是这个栏目最想说的话。技术的进步不是靠几个站在山顶的人挥手一指，是靠几万个坐在屏幕前的人一行一行敲出来的。被记住名字的人只是那几万人里的冰山一角——他们幸运地出现在正确的时机，解决了正确的问题。剩下那些——写了操作系统的大半代码、写了编译器里最枯燥的部分、写了文档、修了最不显眼的 bug 的人——连冰山一角都不算。但这个栏目只有十七篇文章的容量，没有办法把每一个贡献过代码的人写进来。

有一个画面一直在脑海盘旋：2026 年的一天，一个程序员坐在屏幕前，打开编辑器，敲下第一行代码。他不是 Backus，不是 Ritchie，不是 Torvalds——他是一个普通公司的普通工程师。他在用 C 写的操作系统上、在 JavaScript 写的编辑器里、用 Python 写一个后天要上线的功能。他正在穿越七十年的历史——每一字符都踩在前人的肩膀上，他没有意识到这件事。他就是时代的群像本身——不是站在领奖台上的那几个人，是每一个在深夜改着 bug、在日志里翻滚、在 Stack Overflow 和官方文档之间来回切换的人。创造这个数字世界的人，和任何一个程序员一样。

这是他们的故事。

也是所有坐在屏幕前敲着键盘的人的故事。
