## Hello World

```text
用户：帮我写一个 Hello World。
AI：用什么语言？
用户：这七十年来人类发明了那么多种语言——Fortran、Lisp、C、Java、Python……
     你觉得我应该学哪个？
AI：你不需要学了。你现在正在用的就是最后一种：自然语言。
    告诉我你想要什么，我来写。
用户：那写吧。
AI：Hello, World.
```

*这不是一段代码——这是一场对话。编程语言的历史，始于人类学习机器的语言，终于机器学习人类的语言。*

2022 年 11 月 30 日，一个叫 ChatGPT 的东西上线了。

如果你不在那个房间里，很难理解那天到底发生了什么。没有发布会，没有 Keynote，没有铺天盖地的预热。OpenAI 的 CEO Sam Altman 发了一条推文，语气平淡得像在说"我们修了个 bug"：

> "今天，我们发布了一个 ChatGPT 的对话模型研究预览。它让你和 AI 的对话更自然。"

没有人预料到接下来会发生什么。五天内，一百万用户。两个月内，一亿用户——这是历史上增长最快的消费者应用，纪录至今未被打破。Twitter 上开始出现了第一批令人不安的截图：有人让 ChatGPT 帮改一封艰难的邮件，有人让它写一个食谱，有人让它用 Python 写一个小工具——它写出来了。不是"生成一些文本"，是**真的能用**。

![](/images/chatgpt-vibe-coding.png)

*ChatGPT 的对话界面——你在说，它在写。自然语言第一次可以和机器的输出无缝连接。*

然后 GitHub Copilot——2021 年就已经发布了预览版——开始被更广泛地讨论。

然后是 Cursor，一个把 AI 嵌入到编辑器每一个角落的 IDE。

![](/images/cursor-ide-screenshot.png)

*Cursor——编辑器里的每个操作都可以用自然语言完成。传统 IDE 的菜单栏和快捷键正在被对话栏取代。*

然后是 Claude Code、Gemini Code Assist、Windsurf——每一个都试图回答同一个问题：**如果 AI 能写代码，程序员还要做什么？**

![](/images/claude-opus-artifacts-screenshot.webp)

*Claude 的代码生成——你可以把一整段需求说给它听，它把代码写出来放在你面前的 Artifacts 里。*

但在 2022 年底的那几周里，有一个更大的东西在悄悄发生。它不是一个产品，不是一个 API，不是一亿用户——它是一场关于"编程"本身的重新定义。七十年前，人类第一次可以用数学符号和计算机对话。七十年后，人类开始用自然语言和计算机对话——而中间的七十年，是编程语言的历史。

```
Hello, World.
```

没有代码框。因为这已经是最后一种"编程语言"了。

## 七十年，十四门语言

1957 年，Westinghouse 公司的一台 IBM 704 上，一个 Fortran 程序跑起来了。它做的事情在数学上很简单——计算导弹的弹道轨迹——但它在计算机史上完成的转折无法被低估：人类第一次可以用数学公式和计算机对话。`y = x + 1`——五个字符，包含了一个时代的全部野心。

你去看这个栏目的第一篇文章，开头是这样写的：

> *物理学家不想写代码。*

1950 年代的编程是什么？不是"写代码"，是"人肉编译"。物理学家算好了一堆数学公式，然后找到专职程序员，把公式翻译成机器指令——每一步精确到寄存器地址，每一步都不能出错。这个过程缓慢、昂贵、反直觉。Fortran 打破了这一切。John Backus 用 "一个把数学公式翻译成机器指令的系统" 终结了程序员作为"人肉编译器"的时代。

然后 Lisp 来了。John McCarthy 说，计算机能处理的不仅仅是数字，还有符号——还有思想。Lisp 的递归、垃圾回收、代码即数据——这些概念在 1958 年就出现了，比大多数程序员意识到它们的存在早了二十年。

然后是 C。Ken Thompson 写 Unix 的时候，PDP-7 太小了，跑不了 Multics。他需要一个系统语言。Dennis Ritchie 给了他 C——在高级语言中保留了对硬件的绝对控制。1973 年，Unix 内核用 C 重写。操作系统第一次可以用高级语言写了。后来的五十一年里，这个星球上最重要的操作系统——Linux、Windows、macOS——核心全是用 C 写的。

然后是 SQL。Edgar Codd 说：让用户声明他们想要什么，而不是怎么去找。`SELECT` ——一个词，终结了数据库程序员的"指针航海时代"。你不再需要沿着链表遍历数据库，你只需要问。

然后是 C++。Bjarne Stroustrup 想要"带类的 C"。1979 年的 C with Classes，1983 年的 C++。它的核心问题是什么？软件规模太大了，一个人写不完了。面向对象——不是一种语法，是一种组织代码的方式。

然后是 Java。1995 年，互联网刚刚开始爆炸，James Gosling 的"一次编写，到处运行"成了一个时代的口号。JVM 把硬件抽象掉了。

然后是 JavaScript。Brendan Eich 用十天做出了一个语言——不是为了给专业程序员用的，是为了让网页设计师能在浏览器里加一点交互。"表单验证语言"——这是 JavaScript 最初的定位。谁也没想到，它后来统治了浏览器、服务器、桌面、甚至嵌入式设备。

然后是 PHP。Rasmus Lerdorf 用 Perl 写了一个个人主页工具，然后把它开源了。PHP 把代码直接嵌进 HTML——任何一个非技术人员，只要会一点 HTML，就能搭一个留言板。互联网的"建站权"被下放到了每一个人手上。

然后是 R。两个奥克兰大学的统计学家，Ross Ihaka 和 Robert Gentleman，受够了 SAS 和 SPSS 的闭锁和昂贵，在 1993 年写了一个"S 语言的开源实现"。他们不知道这会变成数据科学的基石。

然后是 Python。Guido van Rossum 在 1989 年圣诞节写了一门"为自己"的语言。上篇讲的是它如何成为"胶水"——把 C 和 Fortran 的库粘在一起，变成科学计算的首选前端。下篇讲的是它如何成为 AI 的方言——2015 年 TensorFlow 选择了 Python 作为前端，2016 年 PyTorch 也选了 Python。不是因为 Python 快——它不快——而是因为**研究者需要快速迭代**。Python 的可读性和胶水能力，恰好适合"用 C++ 跑底层、用 Python 调模型"的分层架构。

然后是 Ruby。Yukihiro Matsumoto 想要一种让程序员快乐的语言。Ruby 的答案是"最小意外原则"——让你写代码的时候觉得爽。Ruby on Rails 在 2004 年把 Web 开发的效率推到了极致。但 Ruby 永远没解决性能问题。它证明了"快乐是有代价的"。

然后是 Go。Google 的三个工程师——Rob Pike、Robert Griesemer、Ken Thompson——实在受不了 C++ 的编译速度了。他们说：简单到可以在一个下午学会。goroutines、interface、gofmt——Go 的设计目标不是表达力，是工程师效率。

然后是 Rust。Graydon Hoare 在 2006 年被一台电梯气到了——C++ 写的内存泄漏让电梯每周宕机一次。他住在 21 楼。他开始设计一门"过度设计以求生存"的语言。所有权系统、借用检查器——Rust 的选择是：所有的代价在编译期付清，运行时零开销。2024 年，白宫公开说"用 Rust"。

十四篇故事，十四种语言。每一篇的开头都是一段 Hello World——C 的极简三行、Python 的一行 `print`、Java 的仪式感、Lisp 括号森林满地——

但今天这篇，没有代码了。

## 从写代码到说代码

2021 年 6 月，GitHub Copilot 预览版发布。这是第一个大规模部署的 AI 代码生成工具——把 GPT-3 的能力塞进了 VS Code 的侧边栏。你写一个注释，它补全一段函数。你敲一个名字，它生成整个方法。当时的感觉像什么？像你一直在用手写日记，突然有一天，有人递给你一支笔——你刚写下第一个字，笔自己把剩下的句子写完了。

最早的 Copilot 吐槽帖比他妈的赞美帖还多。"它写出了一堆看似合理但实际上调用了一个不存在的 API 的代码。""它让代码审查变得像考古——你不仅要检查人类写的代码，还要检查 AI 幻觉出来的代码。"但有一个事实无法否认：**它正在改变程序员的工作方式。** 不是取代，是改变。

2022 年 11 月，ChatGPT 上线。Copilot 只做一件事——补全代码——ChatGPT 做所有事：写文章、翻译、改错、推理。然后开发者发现：ChatGPT 写代码的能力比写文章的能力还强。如果你给它一个清晰的需求描述，它能写出一个功能完整的 Python 脚本——不是"代码片段"，是一整个能跑起来的程序。

然后 Cursor 出现了。它不是 Copilot 那样的"插件"，它是一个 IDE——从底层开始就为 AI 协作设计的 IDE。你在 Cursor 里不需要写代码，你只需要告诉它你想要的。它写出来，你验收。不满意，改 prompt。再不满意，它继续改。开发流程从"写 → 调试 → 改"变成了"说 → 检查 → 再说"。

然后是 Claude Code——Anthropic 推出的终端 AI 编程工具。你不需要打开 IDE，在终端里敲一句自然语言命令，它开始自己读你的代码库、改文件、跑测试、commit。你在旁边看着它操作，像一个新手程序员在指导一个老手："不对，不是那个文件。上面那个。对——现在把这个函数的参数改了。"

2025 年有个统计数据在各种开发者社区里流传：在 Y Combinator 的最新一期创业公司中，有超过四分之一的创始人说自己写代码的时候"主要依赖 AI 生成"——不是"用 AI 辅助"，是"主要依赖"。他们说自己的角色不再是"写代码的人"，变成了"评审代码的人"。

这个转变比大多数人意识到的更深远。它不是在问"AI 能不能写代码"——答案已经是"能"了——它是在问另一个问题。

## 编程语言会被 AI 终结吗？

这不是一个"是或否"的问题。

你会发现，编程语言的整个演化史——从 Fortran 到 Rust——就是一个**不断把人类从细节中解放出来的过程**。Fortran 把你从寄存器分配中解放出来。C 把你从汇编中解放出来，但又让你亲自管内存。Java 的垃圾回收把你从内存管理中解放出来。SQL 把你从指针导航中解放出来。Python 把你从类型声明中解放出来。每一个新语言都在做同一件事：让计算机承担更多理解成本，让人类只需要说出意图。

从这个角度看，AI 代码生成不是编程历史的断裂——它是编程历史的**延伸**。Fortran 让你写 `y = x + 1` 而不是 `LOAD A, ADD B, STORE C`。Python 让你写 `print("Hello")` 而不是写一个完整的类。AI 让你写 "帮我写一个读取 CSV 文件并计算每列平均值的脚本"——你连 `import csv` 和 `pandas` 都不用想了。

所以那个"终结"的问题，正确的问法不是"编程语言会不会消失"，而是**"编程语言的抽象层级能高到什么程度"**。

Fortran 的抽象是数学表达式。C 的抽象是内存和指针。SQL 的抽象是关系查询。Python 的抽象是"可读的伪代码"。AI Coding 的抽象是自然语言意图。

每个抽象层级都淘汰了一批"只会在低一层工作"的人，但同时也创造了一批新的角色——那些能在这个层级上更好表达问题的人。Fortran 淘汰了"手写汇编的人肉编译器"，但创造了"编译器工程师"。C 淘汰了"只会写汇编的系统编程者"，但创造了"操作系统开发者"。SQL 淘汰了"只会导航指针的数据库程序员"，但创造了"数据分析师"。AI Coding 正在做的事情也一样——它在淘汰"只会写样板代码的程序员"，但它在创造一种新的角色：**"给出正确问题的人"**。

未来不是没有代码了。未来是代码的生成成本趋近于零。当代码不再值钱，什么才值钱？

答案是：**问题定义、架构判断、需求理解**。

代码不值钱——但知道"这段代码该不该写"依然值钱。代码不值钱——但知道"这个功能对用户到底有没有价值"依然值钱。代码不值钱——但知道"这个算法在这个场景下会不会有不可接受的延迟"依然值钱。

编程语言不会被终结——但"写代码"这件事的价值会被重新定义。就像 Fortran 没有终结编程——它终结了"写汇编"这件事。就像 SQL 没有终结编程——它终结了"用指针导航数据库"这件事。就像 Python 没有终结编程——它终结了"写样板代码"这件事。

## 回望这十四篇文章

在写这个栏目的过程中，我一直在想一个问题。

"写代码"这个动作，在七十年里到底完成了什么？如果答案只是"让机器执行指令"，那 AI 确实已经做到了。但你会发现在每一篇故事里，"写代码"承载了比指令更多的意义。

C 的故事里，Dennis Ritchie 和 Ken Thompson 不是为了写编译器而写编译器——他们是为了让 Unix 能被移植到任何机器上。那是一种**对自由的追求**——你们的硬件可以不一样，但我们的软件要跑在所有地方。

SQL 的故事里，Edgar Codd 不是发明了一种新语法——他是改变了人类和数据的关系。以前是你"导航"数据，现在是数据"回答"你。那是一种**对平等的追求**——不需要是一个程序员，才能问数据库一个问题。

PHP 的故事里，Rasmus Lerdorf 不是写出了最强的 Web 语言——他是让一个高中生在卧室里搭起一个论坛，然后那个论坛变成了一家公司。那是一种**对权力的下放**——建网站不再是精英的事。

Python 的故事里，Guido van Rossum 不是在造一门最优雅的语言——他是在说："代码首先是给人读的，顺便让机器执行。"那是一种**对可读性的尊重**——代码的好坏标准不是"能不能跑"，是"别人能不能看懂"。

Rust 的故事里，Graydon Hoare 不是在和 C++ 较劲——他是在说："我们能不能造一门语言，在你写出代码的那一刻就承诺它永远不会崩溃？"那是一种**对安全的执着**——系统编程不需要带着恐惧工作。

每一篇故事的底色都不是"写代码"，而是"人"。是人面对混乱世界时想理出秩序、面对不公时想下放权力、面对危险时想寻找安全、面对复杂时想追求简单。

写这个栏目之前，我以为我在写编程语言的历史。写了十四篇之后我发现，我写的是**人在试图和其他人对话**——只不过中间站了一台计算机。

Fortran 让物理学家和计算机对话。SQL 让经理和数据库对话。PHP 让普通人和网站对话。Python 让科学家和算法对话。JavaScript 让用户和浏览器对话。

每一门语言都是一座桥。桥的这一端是人——带着问题、想法、困惑的人。桥的那一端是机器——等着被执行的机器。七十年，十四座桥——每座都比前一座更宽、更平、更容易走。

## 你的语言，自己选

2026 年，你打开电脑，打开终端，打开 Cursor，或者打开一台还没被命名的未来编辑器。

你不需要学 Fortran 才能算导弹轨道了。你不需要学 C 才能写操作系统了。你不需要学 Java 才能做网站了。你甚至不需要写 Python——你可以对它说。

但你可以选择学。你可以选择用 C 写一个 hello world，感受一下 1973 年 Ken Thompson 写完 Unix 后的那种简洁。你可以选择用 Lisp 写一个递归，感受一下 1958 年 John McCarthy 说"代码就是数据"时的那个瞬间。你可以选择用 Rust 写一个链表——然后和借用检查器搏斗一下午——然后理解一下白宫为什么说"用 Rust"。

这个栏目的十四篇文章加一篇结语，走完了七十年。从插线板到编译器，从 Fortran 的 `y = x + 1` 到 C 的 `hello, world`，从 SQL 的 `SELECT` 到 Python 的 `print`，从 Go 的 `goroutine` 到 Rust 的 `unsafe`——最后到一段自然语言的 prompt。

这七十年里，「编程」的含义变了无数次。Fortran 时代，编程是翻译数学公式。C 时代，编程是管理内存。SQL 时代，编程是问问题。Python 时代，编程变成了表达逻辑。而今天，编程正在变成：**说出你想要什么，然后和计算机一起搞清楚那到底是不是你想要的**。

但有一件事没变：计算机不理解模糊。AI 理解模糊——但 AI 也是人写的。AI 替你生成的每一行代码，最终都会被编译成 0 和 1，跑在硅片上。这中间的所有抽象层——编译器、解释器、虚拟机、框架、模型——都是这七十年里无数人一砖一瓦搭起来的。

最后一句话，不替读者写了。

打开编辑器吧。用你喜欢的任何语言——包括自然语言——写点什么。

下一行代码，你来决定。
