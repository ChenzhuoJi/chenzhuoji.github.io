代码是什么？早上拿起手机刷脸解锁，那是代码在计算你的脸部特征。打开外卖软件点一份肠粉，那是代码在匹配餐厅、骑手和用户之间的时空关系。刷短视频越刷越上瘾，那是代码在猜测偏好。打车、导航、付款、挂号——每一件和数字设备有关的事，背后都有一行一行的代码在运行。2025 年全世界有超过 1.5 亿人在写代码，GitHub 上每秒钟有几十个仓库被创建。代码从来没有停过。

但代码到底是什么？有人说是菜谱——一步一步告诉计算机怎么做。有人说是乐谱——在恰当的时机演奏出程序。有人说是咒语——念出正确的语法，世界就发生了变化。这些比喻都对了一半。

你听说过"摆线针轮"吗？

那是一种机械传动结构，用在机器人关节和工业机械臂里——齿轮的齿数、齿形、啮合角度决定了机械臂怎么动。一个工程师改变了这些"参数"，机械臂的轨迹就会改变，就像改了一行代码程序的输出就会不同。

更早的时候，中国的算盘也是一种代码——拨珠子的位置和顺序决定了计算结果。织布机上的花版也是——那些孔洞的位置决定了布匹的图案，故宫里精美的云锦，每一匹都是一个古老程序的输出，"源代码"就是那些穿孔的纸板。人类一直在找一种方法，把意志传递给另一个东西，让它替自己干活。算盘珠子是对算盘说"帮我算"，织布机花板是对机器说"织这个图案"，摆线针轮的齿形是对机械臂说"这样转"。这些东西都是中介——连接人和机器的中间语言。这就是代码的本质：它不是写给人类看的——首先是写给机器看的。它把人的意图翻译成机器能执行的指令。

二十世纪中叶发生了一个巨大的转变。计算机出现了。之前的机器只能做一件事——织布机只能织布，机械臂只能转，算盘只能算——但计算机可以做任何事，只要给它不同的代码，它可以是计算器、打字机、游戏机、社交平台、艺术品。一台可以变成任何东西的机器。人们慌了：该怎么和它说话？

第一代编程方式是插线板——把一捆电线的两端插在不同的端口上。想算一个加法？把输出加法器的插孔和输入设备的插孔物理地连在一起。改程序？拔线重插。这不是编程，是装修。然后来了助记符——`ADD R1, R2` 比一捆电线不知道高到哪里去了，但本质上依然是机器的语言，每条助记符对应一条机器指令。然后来了编译器——`y = x + 1`，不需要告诉计算机怎么加、把结果存在哪里、寄存器有几个。写数学公式，编译器替你把一切都翻译成机器听得懂的语言。从插线板到 `y = x + 1`，人类走了十年。从 `y = x + 1` 到对着手机里的AI说"帮我写一个计算器"，中间走了一百多种语言、几万本教程、几百万个开源项目。

这个栏目要讲的就是这个历程。每一门语言背后都有一个人——在某个时刻遇到一个具体的问题，然后决定创造一样东西来解决它。有些人是大公司的研究员，有些人是大学里的教授，有些人在车库、在酒吧、在卧室里写下第一行代码。他们做的事情本质上是一样的：降低人和机器对话的门槛。Fortran 让物理学家不用学汇编，C 让系统程序员不用写汇编，SQL 让业务人员不用写代码就能问数据库问题，JavaScript 让网页从静态变成活的，PHP 让任何人都能搭一个网站，Python 让研究者可以不用关心底层，Rust 让系统程序员不用担心内存崩溃。

每一种语言都在让"人和机器对话"更容易一点。这个趋势有一个终点：有一天，人和机器可以用自然语言对话。这一天已经到了——2026 年的今天，打开任何一个 AI 编程工具，用中文写一句"帮我写一个从 PDF 里提取表格的 Python 脚本"，它能给你一个差不多能跑的程序。不需要知道 Python 语法，不需要了解 PDF 结构，不需要记住任何 API。用自然语言下达意图，AI 替你生成代码。这不是科幻，是今天的日常。这个故事的最后落脚点就在这里——当自然语言也能作为代码的时候，编程语言的历史就翻过了最后一页。但这个栏目的意义不是直奔那个终点，而是走一遍全程。

旅程从 1957 年的 Fortran 开始——计算机还是房间那么大的铁柜子，写代码的人还是穿白大褂的数学家。然后是 Lisp、C、SQL、C++、Java、JavaScript、PHP、R、Python、Ruby、Go、Rust。中间还有一个特别篇，讲一个不是编程语言的东西——GitHub，因为代码的历史只讲语言不讲平台，就像只讲种子不讲土壤。最后一站是一篇结语——当代码不再需要人写的时候，编程意味着什么。为什么是这些语言活了下来？人类创造了几千种编程语言，大部分死了，小部分活着，极少部分改变了世界。改变世界的那些，从来不是因为"技术最好"——Fortran 不是最好的科学计算语言，但它是第一个。C 不是最优雅的语言，但 Unix 选择了它。JavaScript 的设计充满了遗憾，但浏览器选择了它。一个语言的成功，一半是设计，一半是运气，还有一半是时机。

1957 年，西屋电气公司的 IBM 704 房间里，一台打印机正在沙沙地吐纸——上面印着 Fortran 编译器算出来的一条导弹弹道轨迹。一段用数学公式写成的程序，在机器上跑出了正确的答案。Fortran 的故事从那里开始。从此，人类学会了用公式和机器说话。
