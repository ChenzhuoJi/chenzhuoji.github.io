> 我是谁？
>
> 我是一张照片。227 像素宽，227 像素高，3 个颜色通道。
>
> 照片里是一只橘白色的猫——就是我。

在我进入那个叫 AlexNet 的东西之前，我看得见完整的自己。我的左耳是橘色的，右耳也是，但右耳尖有一撮白毛。我的眼睛是琥珀色的。我的尾巴蜷在身体右侧。

我知道我是谁。

然后门开了。

## 96 组眼睛

第一层。96 个窗口同时靠近我。

每个窗口都是 11×11 大小——覆盖我身上大约 121 个像素的区域。但它们看的不一样。窗口里的纹路各不相同：有的像一条水平线，有的像一条垂直线，有些是斜的，有些是某种斑点的组合。

它们从我左上角开始，一块一块地扫过我的全身，每一步移动 4 个像素。

每次扫描，窗口里的纹路和那个位置的像素做一次匹配计算——数值越大，匹配度越高。然后窗口滑到下一个位置。

96 个窗口，各自独立地扫完全身。

每扫完一遍，交出一张 55×55 的响应图——上面标注着：在这张图上，什么地方有符合我这个窗口纹路的特征。

> **说明 · 卷积操作与 ReLU**
>
> ```python
> import torch.nn as nn
>
> # 96 组眼睛，每组 11×11，步长 4
> conv1 = nn.Conv2d(3, 96, kernel_size=11, stride=4)
>
> # 我：一张 227×227 的猫照片
> x = torch.randn(1, 3, 227, 227)
>
> # 96 组眼睛同时看我
> out = conv1(x)   # → (1, 96, 55, 55)
> ```
>
> 输出尺寸：((227 - 11) / 4) + 1 = 55。96 个卷积核，每个输出一张 55×55 的特征图。
>
> 卷积之后是 ReLU——所有负值归零。简单说：这组眼睛在我身上没找到它要找的纹路，它不记负分。
>
> ```python
> relu = nn.ReLU()
> out = relu(out)  # 所有负值 → 0
> ```

扫完之后，我感觉自己被拆散了。

我的一部分——左耳的轮廓——被第 17 号窗口捕捉到了。右耳尖的白毛——第 33 号窗口有回应。我的琥珀色眼睛——第 52 号窗口产生了强烈激活。我的尾巴——第 7 号窗口注意到了一条弧线。

我变成了一叠 96 张图，每张图上高亮着不同部位的不同特征。

但这就是问题所在：这些窗口的响应之间是有竞争的。

如果第 17 号窗口在某个位置发现了很强的左耳轮廓，附近的窗口在同一位置如果也有响应，就会被**压制**。激活的神经元会抑制相邻神经元的激活——生物视觉皮层里叫侧抑制，AlexNet 里叫局部响应归一化。

> **说明 · 局部响应归一化（LRN）**
>
> ```python
> lrn = nn.LocalResponseNorm(size=5, alpha=1e-4, beta=0.75, k=2)
> out = lrn(out)  # 通道间互相抑制
> ```
>
> 每个位置的输出值，除以它相邻通道同一位置的平方和。活跃的通道压制不活跃的邻居——强制多样性。

竞争完，一张 3×3 的筛网滑过来。步长 2，每个窗口只保留最大值。

我被压缩了。55×55 变成了 27×27。

留下的只有最强信号——最确定的边缘、最明确的位置。其余的细节被丢弃了。

> **说明 · 最大池化**
>
> ```python
> pool = nn.MaxPool2d(kernel_size=3, stride=2)
> out = pool(out)  # (1, 96, 27, 27)
> ```
>
> 3×3 窗口，步长 2——重叠池化。相邻窗口重叠 1 个像素，比无重叠池化更平滑。

## 我到哪里了

经过第一关，我不再是一张「猫的照片」了。

我是一堆数值——96 张 27×27 的图，每张对应一组滤波器检测到的特征。左耳、右耳、眼睛、胡须、鼻子——都被分解到了不同的通道里。

但我还能隐约感觉到我是一只猫。这些特征还是局部的、具体的。

到了下一层，这种感觉就要开始模糊了。
