## 万象大会

每年秋天，ImageNet 城都会举办一场盛大的比武大会。来自大陆各处的选手——准确地说是一百万两千张画像——涌入城门，角逐「分类王」的称号。

画像们形态各异：有些是猫，有些是狗，有些是船，有些是一盏台灯。它们被统一做成了 227×227 的尺寸——不多不少，正好 51,529 个像素点，排成一张方方正正的肖像。

今年的比赛有些不同。城主宣布引入一套全新的裁判体系，代号 AlexNet。没人知道它从哪来，只知道它由五个关卡组成。通过全部五关的画像，才有资格进入最终的分类王座。

此刻，第一扇大门缓缓打开。门上刻着一行字：

> **轮廓猎人的长廊。**

---

### 卷积扫描

第一关里站着 96 位猎人。每位猎人手里捏着一块 11×11 的模板——这是一张小小的、刻着特定纹路的卡片。

画像依次入场。每位猎人用它的模板，从画像的左上角开始，逐块扫描。

> **说明 · 卷积操作**
> 
> 卷积核（猎人手中的模板）从输入图像的左上角开始，每次覆盖一个 11×11 的区域。将这个 11×11 的像素值与模板上对应位置的 11×11 个权重逐元素相乘，再求和，得到一个数值——这个数值代表了该区域与模板的「匹配度」。
> 
> 匹配度高 → 该位置存在模板所寻找的特征。
> 匹配度低 → 不存在。
> 
> 然后模板滑动 4 步（stride = 4），重复操作。扫描完一行后，回到最左列并向下滑动 4 步，继续扫描。这就是「卷积」最朴素的含义。
>
> ```python
> import torch
> import torch.nn as nn
>
> conv1 = nn.Conv2d(3, 96, kernel_size=11, stride=4)
> x = torch.randn(1, 3, 227, 227)  # 一张画像
> out = conv1(x)                    # → (1, 96, 55, 55)
> ```

猎人从不看整幅画像。它只看模板能覆盖的那一小块。它在乎的不是整体——它只认识自己卡片上的那一种纹路，然后在画像的每个角落寻找它。

横着扫完一行，向下移动 4 步，再扫一行。

一步，两步。从左上到右下。一幅 227×227 的画像，扫完正好是 55×55 个位置——每幅画像，每位猎人，交出一张 55×55 的响应图。

96 位猎人，96 张响应图。

> **说明 · 输出尺寸**
> 
> 输出尺寸公式：((W - K + 2P) / S) + 1
> 
> Conv1: ((227 - 11 + 0) / 4) + 1 = 55
> 所以输出是 55×55×96。
> 
> ```python
> conv1 = nn.Conv2d(3, 96, 11, stride=4)
> x = torch.randn(1, 3, 227, 227)
> print(conv1(x).shape)  # torch.Size([1, 96, 55, 55])
> ```

## 负分归零

每块扫描区域，猎人都给出一个分数。有正有负。

按过去的规矩——在别的裁判体系里——负分也要保留，正负一起进入下一轮。但 AlexNet 定了一条新规矩：

**所有负分，一律归零。**

> **说明 · ReLU（Rectified Linear Unit）**
> 
> ReLU 的定义极其简单：f(x) = max(0, x)。正数保留，负数裁掉。
> 
> ```python
> relu = nn.ReLU()
> x = torch.randn(1, 96, 55, 55)   # 猎人的响应图
> out = relu(x)                      # 所有负值 → 0
> ```
> 
> 在 AlexNet 之前，神经网络常用的激活函数是 tanh 或 sigmoid，它们将输出压缩在 (-1,1) 或 (0,1) 之间。问题在于：当输入很大或很小时，梯度趋近于零——梯度消失，训练停滞。
> 
> ReLU 在正半轴梯度恒为 1，永远不会饱和。此外 ReLU 不需要指数运算，计算成本极低。

这条规矩看似粗暴，却带来了两个意想不到的好处。

第一，**稀疏性**。大多数区域和猎人的模板并不匹配，得分确实应该是零。清零不是信息损失——是在去除噪音。

第二，**永不饱和**。旧的裁判体系里，分数如果太高或太低就会「卡住」——反正 tanh 的上限是 1、下限是 -1，达到极值后就没法再变化了。新规矩下，正分数有多大就是多大，梯度永远畅通，没有上限。

论文里用 CIFAR-10 做了一个实验：同样的网络结构，ReLU 版本的训练速度是 tanh 版本的 **6 倍**。

> **说明 · ReLU vs tanh**
>
> 实验条件：四层 CNN，CIFAR-10 数据集。要达到 25% 训练误差，tanh 网络需要的迭代次数是 ReLU 网络的大约 6 倍。原因很简单：
> 1. ReLU 正半轴梯度 = 1，无梯度消失
> 2. ReLU 计算只需一次比较，tanh 需要指数运算
> 3. ReLU 产生稀疏激活，信息更集中

## 猎人们学到了什么

96 位猎人一开始是「空」的——模板上的权重是随机初始化的，服从均值为 0、标准差为 0.01 的高斯分布。

在训练过程中，每一轮迭代——120 万张画像依次入场——猎人都在微调自己的模板。正确的匹配被强化，错误的匹配被修正。

最终，96 张模板收敛成了 96 个边缘检测器。有些识别水平边缘，有些识别垂直边缘，有些捕捉纹理的特定朝向，有些对色彩渐变敏感。

> **说明 · 第一层卷积的可视化**
> 
> 将 Conv1 的 96 个卷积核可视化，可以看到它们演化成了 Gabor 滤波器般的纹理检测器——不同频率、不同朝向的边缘。这是 CNN 的经典特征：底层学到低级特征（边缘、颜色），逐层组合成高级语义。
> 
> ```python
> # 训练后，查看学到的东西
> filters = conv1.weight.detach().cpu()  # (96, 3, 11, 11)
> ```

每张 227×227 的画像，经过这 96 道模板的扫描，变成 96 张 55×55 的响应图——画像不再是画像，而是被拆解成了 96 种基本特征的热力图。

从入口到出口，一幅画像变成了一个 55×55×96 的数据块。

第一关，结束。

画像们走出轮廓猎人的长廊，走向下一扇门。门上写着：

**纹理殿堂。**
