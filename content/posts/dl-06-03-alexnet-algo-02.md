> [上一回](/posts/dl-06-02-alexnet-algo-01)，96 位猎人的模板把每幅画像拆解成了 96 张 55×55 的响应图。负分全部归零。
>
> 但比赛还远没有结束。画像们走出长廊，面前是三扇并排的门。门后，是三条截然不同的路。

## 一扇门：收缩之池

第一扇门通往一座水池。

准确地说，是一座 3×3 的滑动筛网。筛网以步长 2 缓缓划过每张 55×55 的响应图。每次覆盖 9 个格子，筛网只允许其中数值最大的那个通过——其余 8 个，当场淘汰。

从入口到出口，55 变成了 27。

> **说明 · 最大池化（Max Pooling）**
>
> 池化层不做任何学习——没有参数。它只是一个固定的过滤器：在每个 3×3 的窗口内取最大值，然后滑动 2 步。
>
> ```python
> pool = nn.MaxPool2d(kernel_size=3, stride=2)
> x = torch.randn(1, 96, 55, 55)
> out = pool(x)  # → (1, 96, 27, 27)
> ```
>
> 这为什么有用？因为图像的邻近像素通常是相似的。保留最大激活值相当于保留「这里有一个边缘」的最强信号，同时丢弃冗余信息。
>
> AlexNet 的特殊之处在于「重叠池化」——核大小 3、步长 2，意味着相邻窗口有 1 格的重叠。论文报告这比传统 2×2、步长 2 的池化（无重叠）在 top-1 上降低了 0.4% 的错误率，而且更难过拟合。

筛网不学东西，没有偏见，没有偏好。它不在乎你是什么特征——它只在乎强度。强的留下，弱的消失。

27×27 的信息密度比 55×55 更高——每个格子代表的不是 1 个像素的信息，而是 9 个格子中最重要的那一个。

## 二扇门：侧抑制之室

第二扇门通向一间特殊的房间。里面的规则是：**相邻的猎人互相压制。**

想象 96 位猎人站成一排，每个人手里举着自己那 55×55 的响应图。在侧抑制之室里，每一位猎人都受到左右邻居的压制——如果某个区域的响应特别强，它就会抑制相邻猎人在同一位置的响应。

这意味着：当一个猎人发现了一个清晰的水平边缘，它附近的猎人就不会在同一位置报告相似的特征。

> **说明 · 局部响应归一化（LRN）**
>
> LRN 模拟了生物神经元的「侧抑制」机制：活跃的神经元抑制相邻神经元。
>
> 对于每个位置 (x, y)，通道 i 的输出经过 ReLU 后，除以一个基于相邻通道同位置激活值的归一化系数：
>
> ```python
> # 这不是完整计算，只是说明 LRN 做了什么
> # nn.LocalResponseNorm 提供了完整实现
> lrn = nn.LocalResponseNorm(size=5, alpha=1e-4, beta=0.75, k=2)
> x = torch.randn(1, 96, 55, 55)
> out = lrn(x)  # 通道间互相抑制
> ```
>
> size=5：相邻 5 个通道参与归一化。alpha=1e-4 控制抑制强度，beta=0.75 控制抑制曲线的形状，k=2 是防止除零的偏置项。
>
> 论文报告 LRN 使 top-1 错误率降低 1.4%，top-5 降低 1.2%。

这听起来残酷，但效果显著。当一个特征在某个区域特别明显时，它不需要邻居们重复确认。这种竞争保证了多样性——不同的通道真正学到了不同的东西，而不是大家的响应图越来越像。

在 AlexNet 的架构中，LRN 被加在 Conv1 和 Conv2 之后、池化之前。Conv3 及之后的层不使用 LRN——到那时，特征已经足够多样，不需要再强制竞争了。

## 三扇门：消失的裁判

第三扇门通向整个比武大会最奇怪的地方。

这里没有猎人，没有筛网，没有竞争。只有一条规则：**每次训练，50% 的裁判随机消失。**

> **说明 · Dropout**
>
> Dropout 是一种正则化技术。在每个训练批次中，以概率 p（通常 0.5）随机将某些神经元的输出置零。这些神经元在该次迭代中完全不参与前向传播和反向传播。
>
> 测试时没有神经元消失。而是将所有权重乘以保留概率 p（权重缩放推理），以保证期望输出不变。
>
> ```python
> dropout = nn.Dropout(p=0.5)
> x = torch.randn(1, 4096)
> out = dropout(x)  # 训练时：~50% 神经元归零
> ```
>
> 训练时，每轮迭代随机屏蔽一组神经元——效果相当于在训练无数个子网络的集成（ensemble）。论文使用 Dropout 于前两个全连接层（FC6 和 FC7），比率 0.5。这是遏制 6000 万参数过拟合的关键手段。
>
> 代价？收敛所需的迭代次数大约翻倍。但值得。

想象一下：一千人小组讨论一个复杂问题。每次讨论随机请一半人离场，剩下的人必须自己找到答案。下一轮，换一批人离场。久而久之，每个人都学会了独立解决问题，而不是依赖某个特定的「天才」。

这就是 Dropout 的本质。

在 AlexNet 里，Dropout 加在最后两关——FC6 和 FC7，那两个拥有 4096 个神经元的巨型全连接层。整个网络 6000 万参数中，94% 集中在这里。没有 Dropout，这些参数会死记硬背训练集，在测试集上一败涂地。

有 Dropout，它们学会了泛化。

---

三扇门，画像们依次穿过。

第一扇留下最强的信号。第二扇让特征之间互相竞争。第三扇让裁判不再依赖彼此。

至此，比赛的真正骨骼已经显现：

```
画像 (227×227×3) 
  → Conv1 + ReLU → MaxPool → LRN 
  → Conv2 + ReLU → MaxPool → LRN
  → Conv3 + ReLU 
  → Conv4 + ReLU 
  → Conv5 + ReLU → MaxPool
  → FC6 + ReLU → Dropout
  → FC7 + ReLU → Dropout
  → FC8 → Softmax → 分类
```

下回，我们走进 Conv2 到 Conv5——更深处的纹理猎人、图案猎手，以及最终的分类王座。
