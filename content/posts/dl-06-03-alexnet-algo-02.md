> [上一回](/posts/dl-06-02-alexnet-algo-01)，96 组眼睛把我拆散成了一叠 27×27 的特征图。我的左耳、右眼、胡须被分到了不同的通道里。
>
> 这还只是前奏。真正的旅程，现在才开始。

## 纹理猎人

走进第二层，256 组新眼睛在等着我。

和第一层的 96 组不同，这些眼睛看的不是原始像素了。它们看的是第一层输出——那 96 张特征图的组合。

这意味着它们识别的不是「左耳的轮廓」，而是**轮廓的组合方式**——边缘如何交汇、纹理如何排列。

5×5 的窗口，逐格滑动（stride=1），边缘补两圈空白（padding=2），输出尺寸不变：27×27。256 张新图。

一只猫的毛发的纹理——橘色和白色交界处的那些细碎变化——被这一层捕捉到了。

然后是第三层、第四层、第五层。384、384、256 组眼睛。窗口缩小到 3×3。它们看的范围越来越小，但组合的信息越来越抽象。

我离「猫」越来越远了。

第五层结束时，我是一叠 6×6×256 的数值——9216 个浮点数。这 9216 个数字已经看不出毛发的橘色、眼睛的琥珀色、尾巴的形状了。它们是一组高维空间中的坐标，只有经过训练的解码器（那些全连接层）才知道怎么读。

> **说明 · 卷积层序列**
>
> ```python
> features = nn.Sequential(
>     # 已走过: Conv1 → ReLU → LRN → MaxPool
>     nn.Conv2d(96, 256, 5, stride=1, padding=2),  # Conv2
>     nn.ReLU(inplace=True),
>     nn.LocalResponseNorm(size=5, alpha=1e-4, beta=0.75, k=2),
>     nn.MaxPool2d(3, stride=2),
>     
>     nn.Conv2d(256, 384, 3, stride=1, padding=1),  # Conv3
>     nn.ReLU(inplace=True),
>     
>     nn.Conv2d(384, 384, 3, stride=1, padding=1),  # Conv4
>     nn.ReLU(inplace=True),
>     
>     nn.Conv2d(384, 256, 3, stride=1, padding=1),  # Conv5
>     nn.ReLU(inplace=True),
>     nn.MaxPool2d(3, stride=2),
> )
> ```
>
> 输入 (N, 96, 27, 27) → Conv2 → ReLU → LRN → MaxPool → (N, 256, 13, 13)
> → Conv3 → ReLU → (N, 384, 13, 13)
> → Conv4 → ReLU → (N, 384, 13, 13)
> → Conv5 → ReLU → MaxPool → (N, 256, 6, 6)

## 两个半场

我注意到一个奇怪的事：从第一层到第五层，我的身体好像是被分成两半处理的。

第一层，96 组眼睛分成了 48+48，各看各的。第二层 256 组分成了 128+128，也不交流。

到第三层才打通——384 组眼睛同时看到两个半场的输出。

> **说明 · GPU 并行**
>
> AlexNet 用两块 GTX 580（各 3GB 显存）训练。模型被纵向切分：
>
> - Conv1、Conv2：GPU0 和 GPU1 独立计算
> - Conv3–Conv5、FC6–FC7：GPU 间通信
> - FC8（1000-way softmax）：合并输出
>
> 这是一种模型并行——不是数据并行。不是"每块 GPU 处理不同图片"，而是"每块 GPU 处理网络的不同部分"。

为什么？因为 2012 年最先进的游戏显卡也只有 3GB 显存，装不下整个网络。所以我被切开了。

## 展平

五层卷积结束，我被展开。6×6×256 的三维结构被拉成了一根 9216 个数字的长串。

这是质变的一刻。

在此之前，我有空间结构——我的值在 6×6 的网格上有位置，相邻的格子代表相邻的空间区域。在此之后，空间消失了。我变成了一根纯粹的向量，每一个数值和它旁边的数值不再有空间关系。

> **说明 · Flatten**
>
> ```python
> x = x.view(x.size(0), -1)  # (N, 256, 6, 6) → (N, 9216)
> ```

## 王座

三扇大门依次打开。

FC6：4096 个神经元。FC7：4096 个神经元。FC8：1000 个神经元。

每个神经元与我的 9216 个数字全部相连。9216 × 4096 = 3700 万个连接。这 3700 万，就是我的"分类王座"。

在训练时，这三扇门里有一个奇怪的规则：每次通过，有 50% 的神经元**随机消失**——它们的输出被置零。下一次，换一批消失。

> **说明 · Dropout**
>
> ```python
> classifier = nn.Sequential(
>     nn.Dropout(p=0.5),     # 训练时 50% 归零
>     nn.Linear(9216, 4096),
>     nn.ReLU(inplace=True),
>     nn.Dropout(p=0.5),     # 又是 50%
>     nn.Linear(4096, 4096),
>     nn.ReLU(inplace=True),
>     nn.Linear(4096, 1000),
> )
> ```
>
> 测试时没有神经元消失。所有权重乘以 0.5（权重缩放推理），保证期望输出一致。
>
> 总参数量：FC6 (37.8M) + FC7 (16.8M) + FC8 (4.1M) = **58.7M**，占 AlexNet 总参数的 94%。

为什么要让神经元消失？想象一个一千人的团队讨论一个问题。每次随机让 500 人离场，剩下的人必须独立找到答案。下一轮换 500 人离场。久而久之，每个人都学会了不依赖某个特定的"天才"——每个人都变得独立可靠。

这就是 Dropout。没有它，那 6000 万参数会精准记住每一张训练图——过拟合。有了它，它们学会了泛化。

最终，FC8 的 1000 个神经元中，某一个的值最高。

第 282 号：**"虎斑猫"**。

有人喊出了我的名字。

## 我是怎么被训练出来的

以上说的这一切——每层眼睛的纹路、每个神经元的权重——都不是一开始就这样的。

最初，它们全是随机的。

权重初始化为均值为 0、标准差为 0.01 的高斯噪声。我能感觉到最初的卷积层——它们在胡乱扫描，什么也认不出来。

真正的训练，从 120 万张图片开始。

每批 128 张。前向传播 → 算误差 → 梯度反向传播 → 权重更新。一轮接一轮，90 轮。

——这就是 AlexNet 的训练循环。

而训练时，我以各种各样的面目出现。

> **说明 · 数据增强**
>
> 每张训练图像在 CPU 上实时变换：
> - 从 256×256 随机裁剪 224×224 区域
> - 随机水平翻转
> - PCA 颜色抖动（沿 RGB 主成分方向加噪声，模拟光照变化）
>
> 每张图 → 2048 种变体。120 万张 → 2.4 亿张有效训练样本。"计算免费"——因为 CPU 在 GPU 算前向时同步完成。

有时候我被裁掉左耳。有时候我被翻转，猫脸朝左。有时候我的颜色被抖动——橘色偏红一点，或者偏黄一点。每次出现都不一样。

我学会了在各种变化中被认出来。

这就是为什么，当我以最标准的样子站在测试集上时——224×224，正中央，猫脸朝右——那个人能准确喊出我的名字。

第 282 号。虎斑猫。

## 回顾篇：AlexNet 架构全景

```
输入:  (N, 3, 227, 227)
    │
Conv1:  96×11×11, s=4  → 55×55×96      (35K)
  ReLU → LRN → MaxPool(3, s=2) → 27×27×96
    │
Conv2:  256×5×5, s=1, p=2  → 27×27×256  (615K)
  ReLU → LRN → MaxPool(3, s=2) → 13×13×256
    │
Conv3:  384×3×3, s=1, p=1  → 13×13×384  (885K)
  ReLU
    │
Conv4:  384×3×3, s=1, p=1  → 13×13×384  (1.3M)
  ReLU
    │
Conv5:  256×3×3, s=1, p=1  → 13×13×256  (885K)
  ReLU → MaxPool(3, s=2) → 6×6×256
    │
Flatten  →  9216
    │
FC6:  9216→4096  + ReLU + Dropout(0.5)   (37.8M)
FC7:  4096→4096  + ReLU + Dropout(0.5)   (16.8M)
FC8:  4096→1000                           (4.1M)
    │
Softmax  →  "虎斑猫"
```
