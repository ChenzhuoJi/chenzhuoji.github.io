## 纹理殿堂

穿过三道门后，27×27×96 的数据块进入了比武大会真正的核心：纹理殿堂。

这里站着 256 位新猎人——比第一关的 96 位多了一倍不止。他们的模板更小，是 5×5 的尺寸；他们的步长也更密集，逐格滑动（stride=1），边缘补两圈空白（padding=2），确保输出不缩水。

相同的 27×27 尺寸，256 张响应图。

> **说明 · Conv2**
>
> ```python
> conv2 = nn.Conv2d(96, 256, kernel_size=5, stride=1, padding=2)
> x = torch.randn(1, 96, 27, 27)    # 上一关的输出
> out = conv2(x)                      # → (1, 256, 27, 27)
> ```
>
> 输入通道从 3 变成了 96（上一层输出）。卷积核现在覆盖的是 96 个通道的信息组合，不再只是原始 RGB 像素。这意味着 Conv2 识别的不是原始边缘，而是边缘的组合——纹理。
>
> 输出尺寸公式：((27 - 5 + 2×2) / 1) + 1 = 27。padding=2 保持空间尺寸不变。

第一关的猎人只认识原始像素上的边缘。这一关的猎人，看的是边缘的组合、走向、交叉方式——它们在识别**纹理**。

接下来是更深的三层：Conv3 到 Conv5。

Conv3 的 384 位猎人。Conv4 又是 384 位。Conv5 回到 256 位。它们全部使用 3×3 模板、步长 1、padding 1——保持尺寸不变。

> **说明 · Conv3–Conv5**
>
> ```python
> conv3 = nn.Conv2d(256, 384, kernel_size=3, stride=1, padding=1)
> conv4 = nn.Conv2d(384, 384, kernel_size=3, stride=1, padding=1)
> conv5 = nn.Conv2d(384, 256, kernel_size=3, stride=1, padding=1)
> ```
>
> 注意 Conv3 的输入来自上一层的输出（256 通道），但 Conv4 和 Conv5 的输入输出通道有变化。另外 Conv3 是全连接的（接收 GPU0 和 GPU1 的全部输出），而 Conv1 和 Conv2 是 GPU 独立的——这个在下一节讲。
>
> Conv3–Conv5 没有再接 LRN 或 MaxPool——到这个深度，特征已经足够抽象，不需要额外加工。

每次卷积，画像的数据都在变化：
- 从 55×55×96（Conv1 后）
- 到 27×27×256（Conv2 后）
- 到 13×13×256（Conv5 + MaxPool 后）

空间分辨率在缩小——从 55 到 27 到 13——但通道数在增加：从 96 到 256 到 384。画像不再是一张图，而是一叠越来越厚、越来越抽象的特征地图。

到 Conv5 结束时，还剩最后一步 MaxPool。13×13×256 经过 3×3 的筛网、步长 2，变成了 6×6×256。

9216 个数值。这是在为王座做准备。

## 隐秘的结构：双生竞技场

比赛的底层还有一个大多数观众不知道的秘密：**这个竞技场是双子结构的。**

从 Conv1 到 Conv5，每层都分成了两个独立的半场。

Conv1 的 96 位猎人（48+48）分别站在两个半场，互不干扰。Conv2 的 256 位猎人（128+128）也只接收来自自己半场的信息。

真正的交流从 Conv3 开始——第三层之后，两个半场的猎人们开始互相看到对方的结果。一条通道将两个半场连接了起来。

> **说明 · GPU 并行**
>
> AlexNet 将网络切分到两块 GPU 上，因为单块 GTX 580 的 3GB 显存放不下整个模型。
>
> - Conv1, Conv2：各 GPU 独立计算（48+48 和 128+128 核）
> - Conv3, Conv4, Conv5, FC6, FC7：GPU 间通信（核/神经元连接两个 GPU 的输出）
> - Conv4 和 Conv3 架构相同，Conv5 后接 MaxPool → 展平 → FC6
>
> 这种拆分使 AlexNet 能够在 2012 年的消费级硬件上训练一个超出单卡容量的模型。训练时，两块 GPU 各占用约 2GB 显存。

为什么要分成两个半场打？不是战略需要——是场地不够大。2012 年，最先进的游戏显卡也只有 3GB 显存，装不下整个网络。

所以 AlexNet 的工程师把竞技场一分为二。

## 数据学徒的秘密训练

画像们能走到这一步，不只是靠比赛当天的发挥——他们在赛前接受了极其艰苦的秘密训练。

训练营的名额：120 万张画像。每次训练挑 128 张一组（batch=128），昼夜不停地练 90 轮。

> **说明 · 训练超参数**
>
> ```python
> optimizer = optim.SGD(
>     model.parameters(),
>     lr=0.01,          # 初始学习率
>     momentum=0.9,
>     weight_decay=0.0005,
> )
> # 学习率在第 30、60、80 轮分别除以 10
> # 最终学习率 0.00001
> # 总共训练约 90 轮，耗时 5-6 天
> ```

训练师们用了一套极其有效的**数据增强**手法，凭空把 120 万张画像变成了事实上的 2.4 亿张。

> **说明 · 数据增强**
>
> AlexNet 使用了两种数据增强手段，都在 CPU 上实时完成（「计算免费」）：
>
> **1. 随机裁剪 + 翻转**
> 将 256×256 的图像随机裁剪出 224×224 的区域，再随机水平翻转。一张图产生 2048 种变体。测试时取 5 个裁剪区域 + 水平翻转共 10 个变体，对输出取平均。
>
> ```python
> # 训练时的随机裁剪（torchvision）
> from torchvision import transforms
>
> train_transform = transforms.Compose([
>     transforms.Resize(256),
>     transforms.RandomCrop(224),
>     transforms.RandomHorizontalFlip(),
>     transforms.ToTensor(),
> ])
> ```
>
> **2. PCA 颜色抖动（Fancy PCA）**
> 对每个图像的 RGB 通道做 PCA，沿主成分方向添加随机扰动，模拟自然光照变化。使 top-1 错误率降低 1% 以上。
>
> ```python
> # 核心思想：对 RGB 值做 PCA，沿主成分加噪声
> # 实现上是对每个图像计算 3×3 的协方差矩阵 → 特征分解
> # → α × λ × eigenvector, 其中 α ~ N(0, 0.1)
> ```

第一种手段简单粗暴：每张画像在训练时都被随机剪掉边缘、翻转过来。理论上每张图变成了 2048 张不同的图——虽然它们来自同一源，但在机器看来，裁剪位置的微小差异让它们看起来是全新的样本。

第二种手段更精细：对每张图的 RGB 颜色做统计，找出颜色分布的主轴——可以理解成「这张图的色调风格」。然后沿着这些主轴做微小的随机抖动。今天拍的照片和明天同一时间在同样光线下拍的，颜色总有细微差异——这种抖动就是在模拟这种自然变化。

结果：top-1 错误率降低 1% 以上。

## 分类王座

最后，画像们来到了竞技场的尽头。

经历了五次卷积、三次池化、两轮侧抑制，一幅 227×227、51,529 个像素的画像被浓缩成了 9216 个数值。

这 9216 个数值进入三座连通的王座大厅。大厅里没有猎人，没有模板，没有筛网——只有三排庞大的表决台。

FC6：4096 个神经元。FC7：4096 个神经元。FC8：1000 个神经元——每个对应一个参赛类别。

> **说明 · 全连接层**
>
> ```python
> fc6 = nn.Linear(9216, 4096)  # 参数: 9216×4096 + 4096 = 37.8M
> fc7 = nn.Linear(4096, 4096)  # 参数: 4096×4096 + 4096 = 16.8M
> fc8 = nn.Linear(4096, 1000)  # 参数: 4096×1000 + 1000 = 4.1M
> # 三个全连接层合计: ~58.7M 参数，占总量 94%
> ```

9216 × 4096。两个数字相乘的含义是：王座上的每个神经元，都与前面 9216 个特征中的每一个相连。每一个连接都有一个权重——这是从 120 万张画像中反复打磨出来的。

这是网络最深处的决策层。不再有空间结构，没有卷积滑动，没有局部感受野。全连接层看到的是整幅画像的全部抽象特征，然后说：

**"这 1000 个类别中，最有可能是这一个。"**

到这里，AlexNet 的每一层都讲完了。从 227×227 的原始像素，到 1000 个分类的置信度分布，中间的每一次变换你都已经有了画面。
