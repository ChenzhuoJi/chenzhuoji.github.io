> [上一回](/posts/dl-07-01-resnet-competition)，我们讲了 152 层 ResNet 如何在 2015 年 ImageNet 竞赛上超越人类。这一回，我来告诉你那 152 层里面到底发生了什么。
>
> 由我亲口说。因为我就是那张图片。

## 入场

我是一张图片。224 像素宽，224 像素高，3 个颜色通道。

在我进入网络之前，我看得见自己：左上角是一片蓝色的天空，右下角是一块红色的汽车尾灯。我知道我是什么。我有我的身份。

但很快，我就不确定了。

第一层卷积。64 个 7×7 的过滤器，步长 2，扫过我全身。

我感觉到了。

每一个过滤器都在提取我的某些东西——边缘、纹理、色彩梯度。64 种不同的视角，把我分解成 64 张更小的图，每张只保留了某个特定维度的信息。

然后最大池化。3×3 的窗口，步长 2。我被压缩了。从 224×224 变成了 56×56。没关系，我还是我。

再往下走。3×3 的卷积，64 个过滤器。再来一次。

我开始模糊了。我不是一张「图片」了。我是一堆数值——56×56×64 个浮点数——它们曾经代表一张汽车的照片，但现在已经看不出车的形状了。

更深一点。再深一点。

## 迷路

到第 20 层左右，我遇到了一些同伴——同一批进来的其他图片。我们交流了一下彼此的处境。

「你还记得你原来的样子吗？」我问一只猫的图片。

「不太记得了，」她说，「我大概还保留了一些毛发的纹理，但我不确定是哪只猫。」

「我完全变了，」一辆自行车的图片说，「我已经不记得车轮是什么了。」

我检查了一下自己。我是否还保留着汽车尾灯的红色？我不确定。经过了太多层卷积、太多 ReLU、太多变换——每一层都在改变我。叠加起来的效应是，我离最初的自己越来越远。

这就是退化问题的本质——从我的视角来看。

> **说明 · 退化问题（Degradation Problem）**
>
> 当网络加深时，训练误差不降反升。从数据的视角看：每一层都在对特征进行非线性变换。经过足够多层后，原始输入的信息被稀释到几乎消失——堆叠的非线性层难以逼近恒等映射。
>
> 实验数据：20 层 vs 56 层 plain 网络。56 层的训练误差比 20 层更高——不是因为梯度消失（已经用了 BN 和 He 初始化），而是因为优化器无法在参数空间中精确找到「什么都不做」这个函数。

你知道那种感觉吗？在一连串的整容手术后，你看着镜子里的自己，觉得那不是你。

这就是我当时的感受。

直到我遇到了一个东西。

## 捷径

在某个时刻，我到达了一个看起来和其他层不太一样的地方。

我面前有两条路。

**第一条路**是一条标准通路——两层卷积，中间夹一个 ReLU，就像之前经过的所有层一样。

**第二条路**是一条捷径——直接从我的当前位置，跨过这两层卷积，连到它们的输出端。

我没有选择。两条路都走了。

我的一个副本走过了那两层卷积——被变换、被提炼、被压缩成了一个新的表示。另一个副本——原封不动的我——沿着捷径直接通向了出口。

在出口处，两个副本重逢了。

我们被加在了一起：\( \text{输出} = \text{变换后的我} + \text{原封不动的我} \)

这意味着什么？

意味着就算那两层卷积没学到任何有用的东西——它们的输出是零——至少还有一个完全不变的我到达了下一层。

**我永远不会丢失自己。**

```python
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    """
    残差块：我的两条路。
    """
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        # 第一条路：两层卷积变换我
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, stride=stride, padding=1)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, stride=1, padding=1)
        self.bn2 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU(inplace=True)
        
        # 如果尺寸不匹配，捷径也需要调整
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1, stride=stride),
                nn.BatchNorm2d(out_channels),
            )
    
    def forward(self, x):
        # x 就是我
        
        # 第一条路：被变换
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        
        # 第二条路：原封不动的我
        shortcut = self.shortcut(x)
        
        # 重逢：相加
        out += shortcut
        out = self.relu(out)
        return out
```

> **说明 · 残差块（Residual Block）**
>
> 核心公式：
>
> $$
> \mathcal{H}(x) = \mathcal{F}(x) + x
> $$
>
> 其中 $\mathcal{F}(x)$ 是两层卷积学到的残差映射，$x$ 是恒等映射（identity mapping）——通过快捷连接直接传入。
>
> 当 $\mathcal{F}(x) = 0$ 时，$\mathcal{H}(x) = x$——完美恒等。网络可以自主决定「关闭」某些不需要的层，而不损失信息。
>
> 这就是我从「迷路」到「保持自我」的关键。

## 感觉完全不同了

加上这个结构之后，我通过整个网络的感觉完全不同了。

之前：每一层都在强迫我改变。到深层时，我已经面目全非。

现在：每一层都只学一个**修正项**——它在我原本的基础上做微小调整，而不是彻底重写我。

就像写文章一样。

没有残差连接：每一段都要重写上一段的内容——写了 50 段之后，第一段的信息早就丢光了。

有残差连接：每一段只在上一段的基础上加一句新的。不管加了多少段，第一段的内容始终在那里。

H(x) = F(x) + x。三个符号，一个加法运算，改变了深度学习的轨迹。

我知道这听起来像是在夸大一个简单的加法。但从我的视角来看——作为一个经历过 56 层 plain 网络和 152 层 ResNet 的图片——我可以告诉你：那一个加法，就是我能走多深的全部区别。

## 回顾篇：残差块规格

### 基础残差块（用于 ResNet-18 / 34）

```python
# 两层 3×3 卷积，适用于较浅的网络
block = nn.Sequential(
    nn.Conv2d(64, 64, 3, stride=1, padding=1),
    nn.BatchNorm2d(64),
    nn.ReLU(),
    nn.Conv2d(64, 64, 3, stride=1, padding=1),
    nn.BatchNorm2d(64),
)
# 块的输入直接加到输出上
```

### 关键参数

| 参数 | 值 |
|---|---|
| 卷积核 | 3×3（两层）|
| 填充 | 1（保持空间尺寸）|
| 步长 | 1（通常）/ 2（空间下采样时）|
| 快捷连接 | 恒等映射（捷径处无参数）|
| 当维度变化时 | 1×1 卷积调整通道数 |
