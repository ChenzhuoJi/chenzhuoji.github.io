欢迎来到我的博客！这是使用 **React** + **Vite** 构建的个人站点。

## 特性

-   **Markdown 渲染** — 所有文章使用 Markdown 编写
-   **数学公式** — 支持 KaTeX 公式渲染

    行内公式：$E = mc^2$

    块级公式：

    $$
    \int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
    $$

-   **代码高亮** — 支持语法高亮

```ts
function greet(name: string): string {
  return `Hello, ${name}!`
}
```

-   **暗色模式** — 支持明暗主题切换
-   **全文搜索** — 按 `Cmd+K` / `Ctrl+K` 搜索
